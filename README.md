# Python Fundamentals Practice

Three small, realistic projects for mastering core Python fundamentals: **basics**, **flow control**, and **functions**. Each project lives in its own folder with a problem statement, expected outcome, and a hint — no solutions included, so you (or contributors) can implement it yourself.

## Why this repo exists

Tutorials show you syntax. These projects make you *use* it in something that resembles a real tool, not a toy exercise. Each one is scoped to run in a terminal with no external dependencies beyond the standard library, so anyone can clone and start immediately.

## How to use this repo

1. Pick a project folder and read its `README.md`.
2. Create your own `solution.py` inside that folder (this file is gitignored-by-convention — don't commit finished solutions to `main`, use a personal branch or fork if you want to keep them).
3. Try to meet the **Expected Outcome** exactly — that's your definition of "done."
4. Only peek at the **Hint** if you're stuck for more than 10–15 minutes.

## Contributing

This repo is intentionally solution-free so it stays useful as a practice ground for anyone. If you want to contribute:

- New fundamentals-level project ideas (same three topics or new ones like loops+data structures, error handling, file I/O)
- Improvements to problem clarity or expected outcomes
- Starter/test files (input validation tests, not solutions) that let learners self-check their output

Please don't submit pull requests containing full solutions — open a discussion or a separate `solutions` branch/fork instead, so the main branch stays a clean challenge for newcomers.

## Suggested skill order

Basics → Flow Control → Functions. Each project assumes you're comfortable with the previous topic's concepts.
